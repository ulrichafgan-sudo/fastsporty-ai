# FastSporty AI ⚽🏆

Application web moderne et interactive de paris sportifs propulsée par Vite, Supabase et animations modernes.

## 🚀 Fonctionnalités

- **Live Match Center** : Suivi des scores et cotes en temps réel.
- **Hero Carousel & Bannières promotionnelles** : Présentation interactive des événements majeurs et offres spéciales.
- **Coupon de Paris Dynamique (BetSlip)** : Calcul automatique des gains potentiels, gestion des paris simples et combinés.
- **Authentification & Gestion Utilisateur** : Modale d'inscription / connexion intégrée avec Supabase.
- **Portail d'Administration** : Gestion et suivi des cotes et événements sportifs.
- **Design Sombre Premium & Responsive** : Interface fluide optimisée mobile et desktop avec effets micro-interactifs et confettis.

## 🛠️ Technologies

- **Frontend** : Vanilla JavaScript (ES Modules), HTML5, CSS3 Moderne (Glassmorphism & animations)
- **Bundler & Dev Server** : [Vite](https://vitejs.dev/)
- **Backend / BDD** : [Supabase](https://supabase.com/) (`@supabase/supabase-js`)
- **Effets visuels** : `canvas-confetti`

## 📦 Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/ulrichafgan-sudo/fastsporty-ai.git

# Accéder au dossier
cd fastsporty-ai

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible sur `http://localhost:3000`.
