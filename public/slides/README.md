# Dossier des Images du Carrousel (FASTSporty AI)

Déposez vos images dans ce dossier pour qu'elles s'affichent automatiquement dans le carrousel central :

1. `slide1-hero.webp` : Slide d'accueil ("Smart Prédiction Real Sport")
2. `slide2-performance.webp` : Slide statistiques ("94 % de réussite globale")
3. `slide3-coupon.webp` : Slide coupon du jour ("Coupon du jour IA, confiance 87 %")
4. `slide4-telegram.webp` : Slide Telegram ("Recevez chaque pronostic en direct")
5. `slide5-analytics.webp` : Slide analyses ("Statistiques, forme et probabilités")
6. `slide6-vip.webp` : Slide abonnement ("Mensuel VIP : tous les coupons + alertes")

### Caractéristiques recommandées :
- **Format** : WebP (ou PNG avec fond transparent)
- **Résolution conseillée** : 800 x 500 px (ratio ~ 16:10)
- **Traitement** : Le carrousel applique automatiquement un léger filtre assombri sur la gauche pour garantir que vos textes restent 100 % lisibles, tout en faisant ressortir vos visuels à droite.
- Tant qu'aucune image n'est déposée, le système affiche automatiquement des visuels vectoriels SVG ultra-haute définition intégrés.
